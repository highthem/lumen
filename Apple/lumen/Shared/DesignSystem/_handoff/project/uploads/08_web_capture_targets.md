## Comment utiliser

Dans Claude Design, après avoir validé l'étape 1 (calibration), tu peux dire :
> "Capture les pages suivantes et résume en 3-5 lignes chacune ce qu'on doit prendre vs éviter pour Lumen : [coller la liste]."

Ou cibler une seule capture :
> "Capture https://www.apple.com/ios/journal/ et propose-moi une palette dark inspirée."

---

## Alternative si web capture indisponible

Si Claude Design n'a pas accès à la web capture pour une raison (URL bloquée, capture limitée), tu peux :
1. Ouvrir l'URL dans Chrome
2. Cmd+Shift+P → "Capture full size screenshot" (ou utiliser une extension)
3. Drag & drop le PNG dans la conversation Claude Design
4. Demander la même analyse

Cette approche fonctionne aussi pour les apps iOS — tu peux capturer le simulateur ou ton iPhone.
