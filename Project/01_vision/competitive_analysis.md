# Analyse compétitive (synthèse)

> Source : brief compétitif produit par agent dédié le 24 avr 2026, vérifié via web search (App Store, Trustpilot, Product Hunt, reviews 2026).

## Tableau de positionnement

| Produit | Positioning | Prix 2026 | Force clé | Faiblesse clé | Chaîne couverte (Réveil / Rituel / IA / Dashboard) |
|---|---|---|---|---|---|
| **Fabulous** | Behavior-change coach (Duke Univ.) | ~40 $/an (jusqu'à 60 $) | Méthodologie rituels guidés | Billing prédateur (Trustpilot 3.4), pas d'IA | Rituel + Dashboard |
| **Alarmy** | "Alarm that forces you out of bed" | 7 $/mois ou 59 $/an | Missions physiques, 4,8★/430k reviews | Bugs iOS, drain batterie, zéro rituel post-réveil | Réveil only |
| **Opal** | Screen Time for Focus | ~60 $/an (variante ~100 $) | Deep Focus, sync cross-device | Bugs de blocage, gamification contradictoire | Dashboard focus only |
| **Rise** | Sleep debt & energy tracker | 36–70 $/an | Energy schedule, caution scientifique | ~25% features utilisées, rigide, billing contesté | Dashboard sommeil/énergie only |
| **Lumen** | Rituel matinal + IA éthique | TBD (voir 05_business) | Chaîne complète + IA + design calm | À construire | **Toute la chaîne** |

## Gaps marché exploitables

1. **Personne ne couvre la chaîne complète** réveil → réflexion → synthèse IA → dashboard. Lumen est le premier.
2. **Aucun concurrent n'a d'IA conversationnelle native sur le matin** — vide marché complet.
3. **Billing toxique omniprésent** → trust = moat.
4. **Bugs iOS non résolus** → barrière technique faible à franchir avec du SwiftUI natif propre.
5. **Dashboard "identité" inexistant** — tous les concurrents sont en mode "métriques".

## Les 4 angles considérés

- **Angle A — "Seul rituel qui démarre à l'alarme"** → pont physique/mental. Moat direct.
- **Angle B — "IA matinale éthique et contextuelle"** → vide marché net.
- **Angle C — "Calm anti-dopamine"** → copy, positioning.
- **Angle D — "Dashboard identité pas métriques"** → design-heavy, long terme.

## Choix retenu pour V1 (livrable PALO + V1 publique)

**A + B combinés**, C comme posture de communication, D en V1.1.

**Positionnement V1 :**
> *"Le seul rituel matinal avec synthèse IA éthique qui démarre à l'alarme."*

**Justification :**
- A sort "gratuitement" du scope brief PALO (alarme + rituel + dashboard).
- B est le seul différentiateur défendable face à Fabulous (qui a 7 ans de contenu/SEO).
- C est une question de voice/copy, pas de code supplémentaire.
- D est riche mais design-heavy, repoussé pour ne pas mettre en péril la deadline.

## Risques d'angle à surveiller

- **Fabulous pourrait ajouter de l'IA.** Advantage temporaire, pas durable à horizon 18 mois.
- **Apple pourrait intégrer un "Morning" natif** dans iOS 27+ (comme Journal l'a été). Veille Apple WWDC à faire.
- **Saturation du positionnement "calm"** → différencier par l'exécution (qualité du flow, prompts IA), pas par le mot "calm".

## Ce qu'on n'imite PAS

- Streaks et badges Fabulous
- Gamification Opal (gems, leaderboards)
- Missions brutales Alarmy
- Dashboard clinique chiffré Rise

## Ce qu'on peut voler

- La qualité du story-telling Fabulous (sans le billing)
- La robustesse du flow Alarmy (sans la brutalité)
- La rigueur UX d'Opal pour le Focus (mais anti-dopamine au lieu d'anti-screen)
- Le design calme et la typographie de Rise (mais moins clinique)
